# Silen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Entregar una app Windows x64 en español con diagnóstico real, drivers, recomendaciones guiadas, sesiones gaming e historial.

**Architecture:** Core define contratos compartidos. Windows y Gaming recopilan datos; App los presenta. El agente principal integra reglas, persistencia y publicación; módulos independientes se delegan en paralelo con propiedad exclusiva de archivos.

**Tech Stack:** C#/.NET 10, WPF, System.Management, LibreHardwareMonitorLib opcional y xUnit.

**Spec:** `docs/superpowers/specs/2026-10-13-silen-design.md`.

## Global Constraints

- Windows 11, x64; .NET 10; interfaz en español.
- Datos reales; ausencia de sensores es desconocida y no cero.
- Ningún ajuste del PC se aplica durante verificación.
- Driver antiguo no equivale a driver desactualizado.
- Acciones guiadas; historial dice que se abrió una guía, no que se aplicó un cambio.
- Datos en LocalAppData; informes sin hostname, usuario ni número de serie.
- Los módulos consumen `SystemSnapshot`, `Finding`, `DriverUpdateResult` y `GamingSession` de Core.

## Review Focus

- WMI o sensores inaccesibles: el informe conserva datos parciales y una nota.
- Windows Update sin red o bloqueado por política: error legible y alternativas oficiales.
- CSV con nombres variables y filas incompletas: rechazar o ignorar con diagnóstico claro, sin generar métricas falsas.
- Cancelación y cierre durante adquisición: evitar carreras o actualizaciones de controles cerrados.
- Escritura local o informe dañado: preservar otros informes y ofrecer error útil.
